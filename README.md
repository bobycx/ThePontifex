# ThePontifex

## Installation 
### System Requirements
Python 3.8 or above required.

Dependencies:
- tqdm
- prompt_toolkit
- termcolor
- prettytable
- sqlite3

### General Installation 
```markdown
git clone https://github.com/KryptosRepublic/ThePontifex && cd ThePontifex
pip3 install -r requirements.txt
python3 pontifex.py [...]
```
